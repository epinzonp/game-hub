# Botecolor

**Goal:** Sort each bottle so every non-empty bottle contains a single color.

**Mechanics and controls:** Select a non-empty bottle, then select a destination. A pour is allowed when the destination has space and is empty or its top color matches the source's top color. The game transfers the contiguous top run of that color, up to the destination's capacity of four. There are always two empty helper bottles.

**Progression and completion:** Complete all bottles to finish a level. Levels 1–3 increase from three to five colors. Complete levels 1 and 2 to continue; after level 3, restart the game. The game randomizes the initial arrangement. It does not track moves or save progress or scores to player records.
